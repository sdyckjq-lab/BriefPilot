# 评审清单

## 受众匹配

- [ ] 设计能清楚回应主要受众。
- [ ] 首屏能让人理解产品或 offer。

## 目标匹配

- [ ] 主要行动清楚、可见、具体。
- [ ] 页面结构服务于业务目标。

## 信息结构

- [ ] 最重要的信息出现在补充信息之前。
- [ ] 必要版块或页面都已出现。

## 品牌与视觉方向

- [ ] 设计遵循已选策略。
- [ ] 设计避开禁止的视觉方向。
- [ ] 设计不依赖泛化 AI 视觉或空洞特效。

## 内容质量

- [ ] 关键说法具体。
- [ ] 有证据点、例子、截图或可信占位。

## 交互与响应式

- [ ] 主要 CTA 行为清楚；实现时覆盖 default、hover、focus、disabled、loading、success 和 error 状态。
- [ ] 次要 CTA 行为清楚，视觉层级保持次要。
- [ ] 产品来源标签和链接文档要么可点击，要么明确只是视觉证明元素。
- [ ] 桌面、平板和移动端都保留主信息和主行动。
- [ ] 移动端标题、CTA 和产品界面可读，没有横向滚动。
- [ ] 覆盖键盘顺序、可见焦点、语义标题、alt text 和 44px 移动端触控目标。
