# 从这里开始

## 你拿到了什么

这是一个 BriefPilot 设计包。它把原始需求整理成一份可以复用的设计说明、视觉系统和评审标准。

## 先看哪个文件

核心文件是 `design-spec.md`。普通用户第一轮只需要完整复制它。

## 首选下一步

首选下一步：复制整个 `design-spec.md` 到你要使用的设计生成工具。

## 怎么选工具

- 想要 React / Next.js 这类可运行界面代码：用 v0。
- 想要高保真、可查看的 HTML 原型：用 huashu-design。
- 想要先探索视觉方向或做多版变化：用 Claude Design。
- 还不确定目标：先回答“我想要可运行代码，还是高保真原型，还是视觉探索？”再选工具。

## 可选导出

`prompts/` 里的平台提示词是可选导出。只有当你明确要用某个平台时才需要复制它们；否则复制 `design-spec.md` 就够了。

## 生成后带什么回来评审

把生成结果带回来即可，可以是本地 `.html` / `.md` / `.txt` / `.json` 文件、生成结果摘要、截图说明或已有视觉评审。

如果你只说“评审”“看看”“检查”，BriefPilot 默认只保存评审报告和下一步建议，不会改你的 brief、`design-spec.md`、生成结果文件或本地代码。
