# huashu-design Adapter

## Use When

Exporting to huashu-design for high-fidelity HTML design work.

## Emphasize

Design context, three directions, `DESIGN.md` visual rules, high-fidelity HTML prototype, real assets, clickable interactions, review dimensions.

## Avoid

Generic one-shot prompts that skip strategy options or omit visual system constraints.

## Prompt Sections

1. Task
2. Context
3. Audience
4. Goal
5. Visual strategy
6. DESIGN.md visual system
7. Required content
8. Constraints
9. Forbidden directions
10. Deliverable
11. Review criteria
