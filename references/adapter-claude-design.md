# Claude Design Adapter

## Use When

The user has already chosen Claude Design, or `START_HERE.md` recommends Claude Design because the desired result is visual exploration, variants, or iterative direction work.

If the user is unsure, do not export this first. Tell them to copy `design-spec.md`.

## Emphasize

Context inspection, `DESIGN.md` reading, clarifying questions when needed, multiple variants, visual artifact, tweak iteration.

## Avoid

Over-prescribing implementation details before the visual direction is explored.

1. Task
2. Context
3. Audience
4. Goal
5. Visual strategy

7. Required content
8. Constraints
9. Forbidden directions
