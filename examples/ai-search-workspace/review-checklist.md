# Review Checklist

## Page Identity

- [ ] 首屏能清楚说明这是 AI 搜索研究工作台。
- [ ] 桌面端无需滚动就能理解可见查询、答案可信度和来源出处。

## Answer And Source Hierarchy

- [ ] 答案正文易读，不被元信息压过。
- [ ] 可信度、来源数量和答案状态靠近答案展示。
- [ ] 引用标记能连接到匹配的来源卡片。

## Source Detail

- [ ] 来源卡片展示标题、摘录、系统或负责人、日期、相关度和链接状态。
- [ ] 来源详情在桌面端、平板和移动端都容易发现。
- [ ] source-unavailable 和 permission-blocked 状态有清楚恢复路径。

## Interaction States

- [ ] 搜索输入包含 empty、input、submitting、failed 和 retry 状态。
- [ ] 答案区域包含 empty、generating、success、partial、low-confidence 和 failed 状态。
- [ ] 来源列表包含 empty、loading、available 和 source-unavailable 状态。
- [ ] 保存/分享控件包含 idle、working、success 和 failed 状态。

## Visual Direction

- [ ] 设计遵循“密集研究工作台”。
- [ ] 设计遵循 `DESIGN.md` 颜色、圆角、间距和组件规则。
- [ ] 设计避开营销优先布局、泛化 AI 发光和虚构来源证明。

## Responsive And Accessibility

- [ ] 移动端顺序是搜索、答案状态、答案正文、来源、来源详情、保存/分享。
- [ ] 移动端没有横向滚动或文字遮挡。
- [ ] 键盘顺序符合核心工作流。
- [ ] focus 状态和 44px 触控目标已覆盖。
