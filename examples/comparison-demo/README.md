# BriefPilot Comparison Demo

Open `index.html` to compare the same vague request used two ways:

```text
帮我做一个 AI 搜索产品官网
```

- Left: a controlled direct-generation baseline example.
- Right: a BriefPilot-enhanced result grounded in `examples/ai-search-landing`.

The baseline is authored for the first public demo. It is not claimed as output from a named tool. See `future-real-output-todo.md` for the evidence needed to add real captured outputs later.

## Files

- `index.html`: openable visual comparison page.
- `comparison-demo.json`: machine-readable demo contract for validation.
- `baseline-controlled.md`: what the controlled baseline represents.
- `briefpilot-enhanced.md`: what the enhanced side is grounded in.
- `future-real-output-todo.md`: follow-up capture contract for real tool outputs.
