# BriefPilot 对比演示

打开 `index.html`，对比同一个模糊需求在两种路径下的差别：

```text
帮我做一个 AI 搜索产品官网
```

- 左侧：直接生成的受控基线示例。
- 右侧：基于 `examples/ai-search-landing` 的 BriefPilot 强化结果。

这个基线是第一个公开演示里的受控样例，不声称来自任何命名工具。以后如果加入真实工具输出，需要按 `future-real-output-todo.md` 记录证据。

## Files

- `index.html`: 可直接打开的视觉对比页面。
- `comparison-demo.json`: 供校验脚本读取的演示约定。
- `baseline-controlled.md`: 说明受控基线代表什么。
- `briefpilot-enhanced.md`: 说明强化结果基于哪些 BriefPilot 资产。
- `future-real-output-todo.md`: 以后采集真实工具输出时需要补齐的记录。
